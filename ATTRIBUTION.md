# Provenance and dependencies

This standalone project was developed as the `final_project` extension of
[agent-harness-course](https://github.com/jiminelee/agent-harness-course), using
the course's module progression as a learning roadmap. The surrounding course
repository and its exercises are not included in this publication.

The benchmark adapter follows the workflow of the
[Hugging Face Agents Course Final Assignment](https://huggingface.co/learn/agents-course/unit4/hands-on)
and [official template](https://huggingface.co/spaces/agents-course/Final_Assignment_Template).
This repository is an independent educational implementation, not an official
Hugging Face release.

GAIA questions, attachments, labels, cached answers and raw traces are not
redistributed here. Access the dataset and evaluation service under their own
terms. Labels used for offline diagnosis are never supplied to the agent.

Dependencies retain their respective licenses. Optional Stockfish binaries are
downloaded separately from the [official project](https://stockfishchess.org/download/)
and are not bundled in this repository. See Stockfish's own GPL license and
source distribution. No blanket license is asserted over third-party material.
